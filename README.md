## 1. Что такое массив в JavaScript?

**Массив в JavaScript** — это структура данных, которая хранит несколько значений в одной переменной. Элементы массива имеют числовые индексы, начиная с `0`.

```js
const fruits = ["apple", "banana", "orange"];
console.log(fruits[0]); // apple
```

Массив может хранить строки, числа, объекты, другие массивы и смешанные типы данных.

## 2. Какими способами можно создать массив?

Основные способы создания массива в JavaScript:

```js
// 1. Через литерал массива
const arr1 = [1, 2, 3];

// 2. Через конструктор Array
const arr2 = new Array(1, 2, 3);

// 3. Через Array.of()
const arr3 = Array.of(1, 2, 3);

// 4. Из строки через split()
const arr4 = "a,b,c".split(",");
```

На практике чаще всего используют литерал `[]`, потому что он проще и читаемее.

## 3. Как получить доступ к элементам массива?

Доступ к элементу массива выполняется по индексу:

```js
const colors = ["red", "green", "blue"];

console.log(colors[0]); // red
console.log(colors[1]); // green
console.log(colors[2]); // blue
```

Индекс первого элемента всегда равен `0`. Также можно использовать метод `at()`:

```js
console.log(colors.at(-1)); // blue, последний элемент
```

К элементу двумерного массива обращаются через два индекса: первый индекс указывает строку, второй — столбец.

## 8. Какие способы сортировки массива существуют в JavaScript?

В JavaScript массивы можно сортировать несколькими способами:

```js
// Сортировка методом sort()
const names = ["Bob", "Anna", "Tom"];
names.sort();

// Сортировка чисел по возрастанию
const nums = [10, 2, 5];
nums.sort((a, b) => a - b);

// Сортировка чисел по убыванию
nums.sort((a, b) => b - a);
```

Метод `sort()` изменяет исходный массив. В современных версиях JavaScript также есть `toSorted()`, который возвращает новый отсортированный массив и не меняет исходный.

## 9. Объясните работу метода sort() и приведите пример сортировки числового массива по возрастанию

Метод `sort()` сортирует элементы массива. По умолчанию он преобразует элементы в строки, поэтому числа могут сортироваться неправильно.

```js
const numbers = [10, 2, 30, 4];
numbers.sort();
console.log(numbers); // [10, 2, 30, 4] — сортировка как строк
```

Для правильной сортировки чисел нужно передать функцию сравнения:

```js
const numbers = [10, 2, 30, 4];

numbers.sort((a, b) => a - b);

console.log(numbers); // [2, 4, 10, 30]
```

Если результат `a - b` отрицательный, `a` ставится раньше `b`. Так получается сортировка по возрастанию.

## 10. Для чего предназначены методы map(), filter() и find()? Приведите примеры

### map()

Метод `map()` создает новый массив, преобразуя каждый элемент.

```js
const numbers = [1, 2, 3];
const doubled = numbers.map(num => num * 2);

console.log(doubled); // [2, 4, 6]
```

### filter()

Метод `filter()` создает новый массив только из элементов, которые подходят под условие.

```js
const numbers = [1, 2, 3, 4, 5];
const even = numbers.filter(num => num % 2 === 0);

console.log(even); // [2, 4]
```

### find()

Метод `find()` возвращает первый элемент, который подходит под условие. Если элемента нет, возвращает `undefined`.

```js
const users = [
  { name: "Anna", age: 20 },
  { name: "Bob", age: 25 }
];

const user = users.find(item => item.name === "Bob");
console.log(user); // { name: "Bob", age: 25 }
```

## 12. В чем разница между методами slice() и splice()? Для каких задач они применяются?

Метод `slice()` возвращает копию части массива и не изменяет исходный массив.

```js
const arr = [1, 2, 3, 4, 5];
const part = arr.slice(1, 4);

console.log(part); // [2, 3, 4]
console.log(arr);  // [1, 2, 3, 4, 5]
```

Метод `splice()` изменяет исходный массив: удаляет, заменяет или добавляет элементы.

```js
const arr = [1, 2, 3, 4, 5];
arr.splice(1, 2);

console.log(arr); // [1, 4, 5]
```

Главное отличие: `slice()` не меняет массив, а `splice()` меняет.

## 13. Объясните назначение методов push(), pop(), shift() и unshift()

```js
const arr = [2, 3];

// push() добавляет элемент в конец массива
arr.push(4); // [2, 3, 4]

// pop() удаляет последний элемент
arr.pop(); // [2, 3]

// unshift() добавляет элемент в начало массива
arr.unshift(1); // [1, 2, 3]

// shift() удаляет первый элемент
arr.shift(); // [2, 3]
```

`push()` и `unshift()` добавляют элементы, а `pop()` и `shift()` удаляют.

## 25. В чем отличие циклов for, while и do...while?

### for

Используется, когда заранее известно количество повторений.

```php
for ($i = 1; $i <= 5; $i++) {
  echo $i . "<br>";
}
```

### while

Выполняется, пока условие истинно. Условие проверяется перед выполнением тела цикла.

```php
$i = 1;

while ($i <= 5) {
  echo $i . "<br>";
  $i++;
}
```

### do...while

Сначала выполняет тело цикла, а потом проверяет условие. Поэтому цикл выполнится минимум один раз.

```php
$i = 1;

do {
  echo $i . "<br>";
  $i++;
} while ($i <= 5);
```

## 26. Что такое цикл?

**Цикл** — это конструкция языка программирования, которая позволяет многократно выполнять один и тот же блок кода, пока выполняется заданное условие.

## 29. Как работают операторы break и continue внутри циклов?

Оператор `break` полностью завершает выполнение цикла.

```php
for ($i = 1; $i <= 10; $i++) {
  if ($i == 5) {
    break;
  }

  echo $i . " ";
}
// Вывод: 1 2 3 4
```

Оператор `continue` пропускает текущую итерацию и переходит к следующей.

```php
for ($i = 1; $i <= 5; $i++) {
  if ($i == 3) {
    continue;
  }

  echo $i . " ";
}
// Вывод: 1 2 4 5
```

## 31. Какие операторы сравнения и логические операторы используются в условных выражениях PHP?

```php

$a === $b  // равно по значению и типу
$a != $b   // не равно

```

### Логические операторы

```php
$a && $b // И
$a || $b // ИЛИ
!$a      // НЕ
$a xor $b // исключающее ИЛИ
```

Пример:

```php
$age = 20;
$hasTicket = true;

if ($age >= 18 && $hasTicket) {
  echo "Вход разрешен";
}
```

## 37. Как работает метод indexOf()? Что возвращает этот метод, если искомый элемент отсутствует в массиве?

Метод `indexOf()` в JavaScript ищет элемент в массиве и возвращает индекс первого найденного элемента.

```js
const fruits = ["apple", "banana", "orange"];

console.log(fruits.indexOf("banana")); // 1
```

Если элемент не найден, метод возвращает `-1`.

```js
console.log(fruits.indexOf("grape")); // -1
```

## 38. Для чего используется метод concat()?

Метод `concat()` используется для объединения массивов. Он не изменяет исходные массивы, а возвращает новый массив.

```js
const arr1 = [1, 2];
const arr2 = [3, 4];

const result = arr1.concat(arr2);

console.log(result); // [1, 2, 3, 4]
```

Также `concat()` может использоваться для объединения строк.

## 39. Как объединить два массива в один?

В JavaScript два массива можно объединить через `concat()`:

```js
const a = [1, 2];
const b = [3, 4];

const result = a.concat(b);
console.log(result); // [1, 2, 3, 4]
```

Также можно использовать оператор spread:

```js
const result = [...a, ...b];
console.log(result); // [1, 2, 3, 4]
```

В PHP для объединения массивов часто используют `array_merge()`:

```php
$a = [1, 2];
$b = [3, 4];

$result = array_merge($a, $b);
```

## 40. Для чего используется оператор switch? В чем его преимущества по сравнению с множественными условиями if...elseif?

Оператор `switch` используется для выбора одного варианта из нескольких на основе значения выражения.

```php
$day = 2;

switch ($day) {
  case 1:
    echo "Понедельник";
    break;
  case 2:
    echo "Вторник";
    break;
  default:
    echo "Неизвестный день";
}
```

Преимущества `switch`:

1. Код легче читать, когда вариантов много.
2. Условия не повторяются много раз.
3. Удобен для проверки одного значения на несколько возможных вариантов.

`if...elseif` лучше подходит для сложных условий, а `switch` — для выбора по одному значению.

## 44. CSS-макеты и адаптивный дизайн

**Flexbox** и **CSS Grid** используются для построения макетов веб-страниц.

### Flexbox

Flexbox удобен для расположения элементов в одном направлении: строка или столбец.

```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

### CSS Grid

Grid удобен для создания двумерных макетов: строки и столбцы одновременно.

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

### Отличия

- Flexbox — лучше для одномерного расположения элементов.
- Grid — лучше для сложной сетки страницы.

### Media query

`media query` позволяет менять стили в зависимости от ширины экрана.

```css
@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
```

Так создается адаптивный дизайн для телефонов, планшетов и компьютеров.

## 45. CSS-селекторы и принцип каскадирования

**CSS-селекторы** указывают, к каким HTML-элементам применяются стили.

2. inline-стили

## 46. Модель CSS Box Model

**Box Model** — это модель, по которой каждый HTML-элемент рассматривается как прямоугольный блок.

Состав блока:

1. `content` — содержимое элемента.
2. `padding` — внутренний отступ между содержимым и границей.
3. `border` — рамка элемента.
4. `margin` — внешний отступ от других элементов.

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  margin: 30px;
}
```

Если используется стандартная модель, итоговая ширина будет:

```text
200px + 20px + 20px + 2px + 2px = 244px
```

Чтобы ширина включала `padding` и `border`, используют:

```css
.box {
  box-sizing: border-box;
}
```

## 52. Как осуществляется поиск и фильтрация данных в SQL?

Для поиска и фильтрации данных в SQL используются операторы `SELECT` и `WHERE`.

### SELECT

`SELECT` выбирает данные из таблицы.

```sql
SELECT name, age
FROM users;
```

### WHERE

`WHERE` задает условие фильтрации.

```sql
SELECT *
FROM users
WHERE age >= 18;
```

### LIKE

`LIKE` используется для поиска по шаблону.

```sql
SELECT *
FROM users
WHERE name LIKE 'A%';
```

Этот запрос найдет пользователей, имя которых начинается на `A`.

### IN

`IN` проверяет, входит ли значение в список.

```sql
SELECT *
FROM products
WHERE category IN ('phone', 'laptop');
```

### BETWEEN

`BETWEEN` выбирает значения в диапазоне.

```sql
SELECT *
FROM products
WHERE price BETWEEN 1000 AND 5000;
```

### ORDER BY

`ORDER BY` сортирует результат.

```sql
SELECT *
FROM users
ORDER BY age DESC;
```

`ASC` — по возрастанию, `DESC` — по убыванию.

## 53. Какую роль играют ключи и связи в SQL?

**Ключи** нужны для уникальной идентификации записей и связи таблиц между собой.

### PRIMARY KEY

`PRIMARY KEY` — первичный ключ. Он уникально определяет каждую запись в таблице и не должен быть пустым.

```sql
CREATE TABLE users (
  id INT PRIMARY KEY,
  name VARCHAR(100)
);
```

### FOREIGN KEY

`FOREIGN KEY` — внешний ключ. Он связывает одну таблицу с другой.

```sql
CREATE TABLE orders (
  id INT PRIMARY KEY,
  user_id INT,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### Типы связей

#### Один к одному

Одна запись одной таблицы связана с одной записью другой таблицы.

Пример: пользователь и паспорт.

#### Один ко многим

Одна запись одной таблицы связана со многими записями другой таблицы.

Пример: один пользователь может иметь много заказов.

#### Многие ко многим

Много записей одной таблицы связано со многими записями другой таблицы. Обычно используется промежуточная таблица.

Пример: студенты и курсы.

```sql
CREATE TABLE student_courses (
  student_id INT,
  course_id INT,
  FOREIGN KEY (student_id) REFERENCES students(id),
  FOREIGN KEY (course_id) REFERENCES courses(id)
);
```

## 54. Как осуществляется управление данными в SQL?

Для управления данными используются операторы `INSERT`, `UPDATE` и `DELETE`.

### INSERT

Добавляет новую запись в таблицу.

```sql
INSERT INTO users (name, age)
VALUES ('Anna', 20);
```

### UPDATE

Изменяет существующие записи.

```sql
UPDATE users
SET age = 21
WHERE name = 'Anna';
```

Важно использовать `WHERE`, иначе могут измениться все строки таблицы.

### DELETE

Удаляет записи из таблицы.

```sql
DELETE FROM users
WHERE id = 1;
```

Без `WHERE` могут быть удалены все записи из таблицы.

## 55. Какие команды SQL используются для создания таблицы базы данных?

Для работы со структурой таблиц используются команды `CREATE TABLE`, `ALTER TABLE` и `DROP TABLE`.

### CREATE TABLE

Создает новую таблицу.

Изменяет структуру существующей таблицы.

Можно добавлять, изменять или удалять столбцы.


Эта команда удаляет и структуру таблицы, и данные внутри нее.

## 56. Что такое SQL? Назначение SQL. DDL, DML и DCL

**SQL** — это язык структурированных запросов, который используется для работы с базами данных. С помощью SQL можно создавать таблицы, добавлять, изменять, удалять и получать данные.

Основные группы команд SQL:

### DDL — Data Definition Language

Команды для работы со структурой базы данных.

```sql
CREATE TABLE users (
  id INT PRIMARY KEY,
  name VARCHAR(100)
);
```

Примеры DDL-команд:

- `CREATE` — создать объект базы данных;
- `ALTER` — изменить структуру;
- `DROP` — удалить объект.

### DML — Data Manipulation Language

Команды для работы с данными внутри таблиц.

```sql
INSERT INTO users (name)
VALUES ('Anna');
```

Примеры DML-команд:

- `INSERT` — добавить данные;
- `UPDATE` — изменить данные;
- `DELETE` — удалить данные;
- `SELECT` — получить данные.  

Иногда `SELECT` отдельно относят к DQL — Data Query Language, но в учебных материалах его часто рассматривают вместе с командами работы с данными.

### DCL — Data Control Language

Команды для управления правами доступа.

```sql
GRANT SELECT ON users TO manager;
REVOKE SELECT ON users FROM manager;
```

Примеры DCL-команд:

- `GRANT` — выдать права;
- `REVOKE` — забрать права.
